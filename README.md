# Two Hearts Cafe POS v1

Local-first cafe POS built with Node.js + Express + SQLite.

## Run
1. Install Node.js 24 LTS or newer.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.

Default first-run login: `admin` / `admin123`.

## Included
- Login/session
- SQLite database
- Menu management
- Stock and low-stock tracking
- Dine-in / takeaway
- Tables
- Cart, discount, GST
- Cash / UPI / card
- Invoice + print
- Orders history + reprint
- Dashboard + reports
- Settings
- Database backup download

## Commercial handover checklist
Change the default password, enter the real menu/prices, verify GST/tax treatment with the cafe/accountant, test the exact printer and paper size, and test backup/restore on the actual shop computer.
